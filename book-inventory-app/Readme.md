# 📚 Book Inventory Application

A responsive and interactive **Book Inventory Management** interface. This project was developed as a hands-on lab to master advanced **CSS Attribute Selectors**, structural pseudo-classes, and complex table styling within the Responsive Web Design certification path.

## 🚀 Key Features

*   **Advanced Attribute Selectors:** Implemented precise CSS logic using `[class~="value"]` to target specific elements based on partial class matches (`one`, `two`, `three`).
*   **Dynamic Visuals:** Utilized `linear-gradient` backgrounds to create status-coded rows (`Read`, `To Read`, `In Progress`) and dynamic rating indicators.
*   **Structural Precision:** Clean table-based layout using `thead` and `tbody` to organize large datasets efficiently.
*   **CSS Pseudo-Classes:** Leveraged `:first-child`, `:nth-child()`, and nesting structures to style rating elements dynamically without changing individual HTML nodes.

## 🛠️ Technical Stack

*   **HTML5:** Semantic table structure and span-based data visualization.
*   **CSS3:** 
    *   `linear-gradient` for modern UI aesthetics.
    *   Advanced attribute selection and descendant targeting.
    *   `display: inline-block` for precise layout control.
    *   Complex geometric styling (borders, border-radius, and margin control).
