# 📰 Classic Newspaper Layout (CSS Grid Lab)

A responsive, print-inspired digital newspaper layout built with advanced **CSS Grid** (`grid-template-areas`, `grid-template-columns`, and `grid-template-rows`), featuring a classic broadsheet aesthetic. 

This project was developed as part of the FreeCodeCamp Responsive Web Design certification labs and customized with a bespoke, vintage publication design.

## ✨ Features & Design Highlights

* **Advanced CSS Grid Architecture:** Utilizes explicit named grid areas (`grid-template-areas`) to map out a complex multi-column broadsheet layout cleanly.
* **Vintage Broadsheet Aesthetic:** Styled with custom color palettes (`#f7f3eb` paper background, classic dark borders, and traditional red accent colors) to mimic physical newsprint.
* **Typographic Hierarchy:** Combines high-contrast `Anton` headers with elegant `Baskerville` and `Georgia` serif body text, complete with justified paragraphs.
* **Stylized Media Elements:** Includes grayscale-filtered images and custom dashed/double borders to evoke a retro print journalism vibe.
* **Structured Content Sections:**
  * Broadsheet-style Header (`.title`) spanning the full width.
  * Main Feature Article (`.feature-article`) with dedicated column coverage.
  * Cover Image (`.cover-image`) acting as a visual anchor.
  * Secondary Section (`.secondary-article`) for in-depth coverage.
  * Three-column footer row for brief updates (`.small-article1`, `.small-article2`, `.small-article3`).

## 🛠️ Built With

* **HTML5** (Semantic layout tags: `<main>`, `<header>`, `<article>`, `<figure>`)
* **CSS3** (CSS Grid, CSS Custom Properties, Flexbox, Advanced Selectors, Filters)
