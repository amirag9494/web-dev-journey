☕ Camper Cafe Menu
A responsive and beautifully styled cafe menu web page built as part of the freeCodeCamp Responsive Web Design certification.

🚀 Features
Clean and semantic HTML5 structure (main, section, article, address).
Custom styling using CSS3 (Selectors, Pseudo-classes, Flexbox-like inline blocks).
Visually appealing layout featuring background textures, custom fonts, and centered elements.
Interactive link pseudo-classes (:visited, :hover, :active) for enhanced user experience.
🛠️ Technologies Used
HTML5
CSS3
Git & GitHub
💻 How to View
Simply clone the repository and open index.html in any modern web browser:

git clone [https://github.com/YOUR-USERNAME/cafe-menu.git](https://github.com/YOUR-USERNAME/cafe-menu.git)
cd cafe-menu
xdg-open index.html  # On Linux
