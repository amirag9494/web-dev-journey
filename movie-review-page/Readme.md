Movie Review Page Lab
A modern, responsive, and visually appealing Movie Review Page built as part of the FreeCodeCamp curriculum labs.

🚀 Features
Semantic HTML5 Structure: Uses proper structural elements like <main>, <h1>, <h2>, <p>, <ul>, and <li>.
Web Accessibility (A11y):
Descriptive alt text for the movie poster image.
Screen-reader optimization using aria-hidden="true" on the visual rating stars.
Cinematic CSS Styling: Custom dark-theme styling inspired by modern streaming platforms, utilizing system fonts, clean spacing, and subtle box shadows.
