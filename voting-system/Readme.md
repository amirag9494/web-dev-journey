# Voting System - freeCodeCamp Lab

An interactive polling application built using Vanilla JavaScript, leveraging `Map` to manage poll options and `Set` to prevent duplicate votes from the same user ID.

## Features
- **Dynamic Options**: Add new choices to the poll instantly with duplicate and empty-input validation.
- **Secure Voting**: Track unique voters per option utilizing JavaScript `Set` data structures.
- **Real-time Results**: Generate formatted textual breakdowns of total vote counts.

## Tech Stack
- **JavaScript (ES6+)**: Core logic (`Map`, `Set`).
- **HTML5 & CSS3**: Clean, modern, and minimalist user interface.

## How to Run
1. Clone or download the files (`index.html`, `style.css`, `script.js`) into the same directory.
2. Open `index.html` in any modern web browser.
