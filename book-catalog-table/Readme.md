📚 Book Catalog Table
A clean, responsive, and semantic HTML5 data table with custom CSS styling built as part of the freeCodeCamp Responsive Web Design Certification curriculum.

🚀 Overview
This project showcases proper HTML table structure (<thead>, <tbody>, <tfoot>) combined with modern CSS techniques (zebra striping, dynamic row hover effects, clean typography, and responsive container wrapping).

✨ Features
Semantic Data Architecture: Uses structural HTML tags (table, thead, tbody, tfoot, tr, th, td).
Column Spanning: Implements colspan="4" inside tfoot to cleanly present total catalog statistics.
Custom Visual Styling:
Slate dark header theme (#2c3e50) with uppercase, tracked headers.
Alternating row styling (tr:nth-child(even)) for enhanced data readability.
Interactive row hover highlights (tr:hover).
Subtle box-shadow and soft rounded borders.
🛠️ Tech Stack
HTML5: Semantic markup for structured data tabular displays.
CSS3: Custom layout styling, border collapse, and state pseudo-classes.
