Blog Post Card Component
A clean, responsive, and modern blog post card component built with HTML5 and CSS3 as part of the Responsive Web Design curriculum. This project focuses on mastering backgrounds, borders, padding, margins, and card layout design.

🚀 Features
Semantic HTML Structure: Built using proper semantic tags (div, img, h2, p, a).
Card Styling: Features a clean white background, smooth rounded corners, and a structured layout.
Responsive Image Header: Includes a cover photo that spans the full width of the card with a custom bottom border.
Interactive Button State: Styled call-to-action ("Read More") button with a smooth hover effect and custom margins/padding.
📂 Project Structure
├── index.html    # Main HTML document for the blog post card structure
└── styles.css    # Custom CSS styles, borders, margins, and hover effects
