# Markdown to HTML Live Converter 🚀

A lightweight, modern, and responsive **Markdown to HTML Converter** built with vanilla JavaScript, HTML5, and CSS3. It features a split-screen dark-mode interface that converts basic Markdown syntax into rendered HTML in real-time.

---

## ✨ Features

- **Real-Time Live Preview**: Instant conversion as you type in the markdown editor.
- **Supported Markdown Elements**:
  - Headings (`#`, `##`, `###`)
  - Bold text (`**text**` or `__text__`)
  - Italic text (`*text*` or `_text_`)
  - Images (`![alt-text](image-source)`)
  - Links (`[link text](URL)`)
  - Blockquotes (`> quote`)
- **Modern Dark UI**: Clean, distraction-free split-pane workspace designed with a sleek dark theme and custom scrollbars.
- **No External Dependencies**: Built entirely with pure, native web technologies (Vanilla JS & Regular Expressions).

---

## 🛠️ Built With

- **HTML5**: Semantic markup structure.
- **CSS3**: Flexbox layout, custom styling, and modern dark color palettes.
- **JavaScript (ES6+)**: Custom parsing logic using powerful Regular Expressions (`RegEx`) and DOM manipulation.
