# Bank Account Management Program

A clean and minimalist Object-Oriented JavaScript application for managing bank account transactions, balances, and generating reports. Built as part of a programming lab challenge.

## Features

- **Object-Oriented Design**: Built using ES6 classes (`BankAccount`).
- **Deposit Management**: Add funds with validation rules (must be greater than zero).
- **Withdrawal Logic**: Securely withdraw funds based on available balance and valid inputs.
- **Transaction History**: Keeps track of all deposits and withdrawals with structured object logs.
- **Reporting Methods**: Easily list all deposits or withdrawals comma-separated.
- **Warm Minimalist UI**: Clean classic design interface styled with warm sepia and cream tones.

## Code Structure

- `script.js`: Contains the core `BankAccount` class and transaction logic.
- `index.html`: Interactive user interface linking the logic to DOM elements.
- `style.css`: Warm, distraction-free typography and design layout.

## How to Run

1. Clone or download the repository to your local machine.
2. Ensure `index.html`, `script.js`, and `style.css` are in the same folder.
3. Open `index.html` in any modern web browser.
