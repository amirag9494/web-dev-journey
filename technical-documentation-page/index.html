Introduction

Python is a high-level, interpreted programming language known for its clear syntax and readability.

print("Hello, World!")

Variables and Types

Variables are containers for storing data values in Python without explicit declaration.

Python has various data types including integers, floats, strings, and booleans.

x = 10; name = "Amir"
  • Dynamic typing
  • Memory management
Conditional Statements

Conditional statements like if, elif, and else are used to perform different actions based on conditions.

Indentation is crucial in Python to define the scope of the code blocks.

if x > 5: print("Greater")
  • Logical branching
  • Indentation rules
Functions

Functions are reusable blocks of code that perform a specific task when called.

You define a function in Python using the def keyword followed by the function name.

def greet(): print("Hi")
  • Code reusability
  • Parameters and return values
