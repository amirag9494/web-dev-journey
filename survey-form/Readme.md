📋 Developer Learning & Career Survey Form
A responsive and accessible HTML5/CSS3 survey form project created for the freeCodeCamp Responsive Web Design Certification (Certification Project 1).

🚀 Overview
This project satisfies all 44 test requirements for the freeCodeCamp Survey Form specification. It features clean visual presentation, accessible form structures (labels properly connected, semantic tags), custom CSS styling, and client-side HTML5 validation.

✨ Features
100% freeCodeCamp Test Compliant: Covers all required IDs, types, ranges, placeholders, and semantic constraints.
Form Controls Included: Text inputs, email input, number bounds, select dropdown, grouped radio buttons, multi-selection checkboxes, and a feedback textarea.
Modern Responsive Design: Card-based UI container styled with CSS custom variables, custom input focus states, and interactive submit buttons.
🛠️ Tech Stack
HTML5: Semantic form controls (form, label, input, select, textarea, button).
CSS3: Flexbox, CSS Variables, custom component styling, hover/active pseudo-states.
