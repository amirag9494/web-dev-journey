# Weekly Meeting Availability Schedule

A responsive and accessible web application built as part of the FreeCodeCamp Responsive Web Design certification labs. This project displays a weekly team availability schedule using an HTML table, advanced CSS grid/flexbox styling, CSS variables, and custom gradients.

## 🚀 Features

* **Structured Data:** Organized tabular layout showcasing days of the week and specific time slots.
* **Color-Coded Availability:** Dynamic background colors utilizing custom CSS variables (`--color0` to `--color5`) to represent team member availability levels.
* **Accessibility (a11y):** Fully integrated `scope` attributes for table headers and descriptive `aria-label` attributes for each availability data cell.
* **Custom Styling & Borders:** Alternating row borders (`.sharp` and `.half` classes) styled with solid and dashed custom border variables.
* **Visual Legend:** A dedicated legend section complete with a hard-lined linear gradient reflecting the availability color scale.

## 🛠️ Built With

* **HTML5** (Semantic elements, tables, accessibility attributes)
* **CSS3** (Custom properties/variables, flexbox, linear gradients, pseudo-classes)
