# 📰 Newspaper Article Project

A responsive and styled digital newspaper article webpage built as part of the FreeCodeCamp Responsive Web Design certification. This project focuses heavily on advanced CSS typography, font sizing units (`rem` and `em`), text transformations, and pseudo-elements.

## 🚀 Features & Typography Focus

* **Custom Root Font Sizing:** Establishes a foundational root font size (`24px`) on the HTML document to manage relative scaling.
* **Newspaper Container:** Uses an `.newspaper` wrapper with a standard font size (`16px`) and `'Open Sans'` font family.
* **Classic Newspaper Header Styling:** 
  * Features a bold newspaper name in `Times New Roman` uppercase.
  * Includes article dates, headlines, and italicized thin sub-headlines (`font-weight: 100`).
* **Advanced Text Formatting (`.text`):**
  * Configured with custom paragraph text indentation (`text-indent: 20px`) and line height (`2em`).
  * Utilizes the `::first-letter` pseudo-element to create an editorial drop cap effect (bold and twice the font size).

## 🛠️ Built With

* **HTML5** (Semantic elements)
* **CSS3** (Typography rules, selectors, and pseudo-elements)
