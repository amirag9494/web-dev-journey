# Email Privacy Masker 🛡️

A lightweight, modern web utility built with **Vanilla JavaScript**, **HTML5**, and **CSS3** that masks the username part of any email address for privacy and data protection.

![Project Preview](https://img.shields.io/badge/status-active-success) ![JavaScript](https://img.shields.io/badge/javascript-%23F7DF1E.svg?style=flat&logo=javascript&logoColor=black)

## Features ✨

- **Custom Masking Characters:** Choose between Asterisks (`*`), Hyphens (`-`), Bullets (`•`), or Hashes (`#`) to hide sensitive information.
- **Email Validation:** Ensures that the input string follows a proper email format before processing.
- **One-Click Copy:** Quickly copy the masked result to your clipboard with visual feedback.
- **Recent History:** Automatically tracks and displays the last few masked emails in a clean session history.
- **Monospace Alignment:** Guarantees perfect character alignment for masked symbols.
- **Responsive & Minimalist UI:** Designed with a sleek dark-mode layout.
