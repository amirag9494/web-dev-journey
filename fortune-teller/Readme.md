# 🔮 Digital Fortune Teller

A sleek, modern, and minimalist web application built with HTML, CSS, and JavaScript that generates random fortunes to brighten your day (or give you a fun glimpse into the future!). 

This project is part of my JavaScript learning journey, transformed from a simple console script into a fully functional interactive web mini-app.

---

## ✨ Features

- **Interactive Experience:** Click the button to get a brand-new random fortune instantly.
- **Expanded Pool:** Includes 10+ unique and engaging fortunes.
- **Modern Minimalist UI:** Designed with a dark theme and smooth transitions for a clean aesthetic.
- **Responsive Layout:** Looks great on both desktop and mobile devices.

---

## 🛠️ Built With

- **HTML5:** Semantic structure and layout.
- **CSS3:** Modern styling, flexbox centering, and dark-mode color palette.
- **JavaScript (ES6+):** Array manipulation, random number generation (`Math.random`, `Math.floor`), and DOM event handling.
