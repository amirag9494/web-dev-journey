🪪 Professional Business Card
A clean, responsive, and modern digital business card web page built as part of the freeCodeCamp Responsive Web Design labs.

✨ Features
Semantic HTML5 Structure: Built using proper structural tags (div, main, section, address, hr).
Custom CSS3 Styling: Styled with custom colors (rosybrown background, custom card color, centered layout, and 16px font size).
Profile Section: Features a profile image with responsive max-width settings, alongside clear designation and company details.
Interactive Elements: Clean anchor links for portfolio and social media channels (Twitter, LinkedIn, GitHub) with custom states and no underlines.
Pixel-Perfect Design: Adheres strictly to precise margins, padding, and centered text alignment.
🛠️ Technologies Used
HTML5
CSS3
Git & GitHub
