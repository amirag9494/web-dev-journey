# 🚀 Personal Portfolio & Developer Hub

A modern, responsive, and feature-rich personal portfolio built using **HTML5** and **CSS3** (CSS Grid, Flexbox, Custom Properties, and Glassmorphism effects). This project serves as a centralized hub to showcase web development projects, technical skills, and professional background.

## ✨ Features & Design Highlights

* **Glassmorphism Navbar:** Fixed header with a blurred backdrop effect (`backdrop-filter`) that stays pinned to the top of the viewport.
* **Immersive Hero Section:** Full-viewport (`100vh`) welcome section featuring radial gradient styling and clear calls to action.
* **Responsive Grid Layouts:** Dynamic skill and project cards built with CSS Grid (`auto-fit`, `minmax`) that seamlessly adapt to any screen size.
* **Interactive Elements:** Smooth hover transformations, accent highlights, and clean card-based UI containers.
* **Comprehensive Sections:**
  * Home / Welcome area with personal branding.
  * About Me background summary.
  * Technical Skills grid (Python, Linux, HTML/CSS, Git).
  * Featured Projects tiles linking directly to repositories.

## 🛠️ Built With

* **HTML5** (Semantic structure: `<nav>`, `<section>`, `<footer>`, etc.)
* **CSS3** (Flexbox, CSS Grid, Custom Properties, Media Queries, Transitions)
