🚀 Developer & Academic Event Hub
A responsive and semantically structured web application designed to showcase tech conferences, developer workshops, and academic computer science events.

📌 Project Overview
This project was built as part of my learning journey in web development. It leverages Semantic HTML5 to ensure maximum accessibility, search engine optimization (SEO), and clean document architecture, paired with a minimal CSS layout.

✨ Features
Semantic HTML5 Architecture: Built using standard tags like <header>, <main>, <section>, <article>, and <nav>.
Internal Anchor Navigation: Smooth jumping between "Upcoming Events" and "Past Events".
Accessible & SEO-Friendly: Properly structured heading hierarchies (<h1>-<h3>) and informative image alt text.
Clean Responsive Design: Styled with lightweight CSS for readability and a modern aesthetic.
🛠️ Tech Stack
HTML5 (Semantic layout)
CSS3 (Internal styling)
Git & GitHub (Version control)
