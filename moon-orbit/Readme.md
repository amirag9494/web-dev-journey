# 🌙 Moon Orbit Animation (CSS Animation Lab)

A sleek, lightweight web animation depicting the Moon's orbital rotation around the Earth, built using **HTML5** and **CSS3** (Flexbox, Absolute Positioning, Transforms, and Custom Keyframe Animations). 

This project was completed as part of the freeCodeCamp Responsive Web Design certification labs.

## ✨ Features & Technical Highlights

* **Pure CSS Animation:** Smooth, continuous 360-degree rotation utilizing custom `@keyframes` and linear timing functions.
* **Precise Geometric Positioning:** Uses absolute positioning combined with advanced `transform: translate()` percentages to perfectly center celestial bodies within their relative coordinate spaces.
* **Flexbox Centering:** Implements a viewport-centered flex layout for structural stability.
* **Clean Visual Hierarchy:** Styled with deep space aesthetics and contrasting planetary colors.

## 🛠️ Built With

* **HTML5** (Semantic container elements: `.space`, `.earth`, `.orbit`, `.moon`)
* **CSS3** (CSS Grid/Flexbox concepts, `transform`, `border-radius`, `@keyframes` animations)
