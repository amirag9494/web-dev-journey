Multimedia Player Lab
A modern, responsive, and accessible Multimedia Player built as part of the FreeCodeCamp curriculum labs. This project features integrated audio and video playback along with synchronized subtitles and transcripts.

🚀 Features
Semantic HTML5 Structure: Built with clean structural elements including <h1>, three distinct <section> blocks, <audio>, <video>, <source>, and <track> tags.
Web Accessibility (A11y):
Descriptive aria-label attributes on media players for screen-reader compatibility.
Subtitle track configuration (kind, srclang, label) for inclusive viewing.
Immersive CSS Styling: Custom dark-theme styling inspired by modern media streaming applications, featuring card-based layouts, responsive video sizing, and elegant typography.
