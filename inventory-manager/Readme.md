# Inventory Management System

A robust, object-oriented JavaScript inventory management program featuring a sleek dark-themed UI. It handles product additions, stock updates, case-insensitive searches, stock removals, and automatic clean-up of out-of-stock items.

## Features
- **OOP Architecture**: Built using clean ES6 classes (`InventoryManager`).
- **Case-Insensitive Search (`findProductIndex`)**: Automatically normalizes product names.
- **Dynamic Stock Updates**: Merges quantities for existing items or creates new records.
- **Controlled Removal (`removeProduct`)**: Validates stock sufficiency and removes items if quantity drops to zero.
- **Interactive Web Interface**: Complete with real-time table rendering and system console logs.

## Technologies Used
- JavaScript (ES6+)
- HTML5 & CSS3 (Responsive Grid layout)
