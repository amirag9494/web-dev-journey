🎯 CS Career & Academic Goal Survey
A responsive, semantic HTML5 and CSS3 interactive survey application designed to gather structured feedback regarding Computer Science academic planning, study routine self-assessments, and backend development career milestones.

📌 Project Overview
This project focuses on building accessible, well-structured web forms adhering to modern HTML5 semantic standards. It utilizes native form elements, clear structure using fieldsets, validated input types, and clean CSS styling to deliver an optimized user experience.

✨ Key Features
Semantic HTML5 Form Architecture: Implements <fieldset>, <legend>, <label>, <input>, <select>, and <textarea> for standard-compliant data entry.
Form Controls & Constraints: Includes required inputs, field length restrictions (size), numerical bounds (min/max), radio choice groups, and multi-select checkboxes.
Custom CSS Styling: Lightweight embedded CSS utilizing modern layouts, responsive container sizing (max-width), custom input formatting, and hover states.
User-Centric Design: Tailored for Computer Science students tracking study consistency and specialized learning goals (e.g., Python Backend, DAAD scholarship prep).
🛠️ Tech Stack
HTML5: Semantic form controls and document structure.
CSS3: Custom layout, typography, box-model styling, and responsive form constraints.
Git & GitHub: Version control and repository hosting.
