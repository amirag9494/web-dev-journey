# Lunch Picker & Menu Manager 🍽️✨

A clean, interactive web utility built with **Vanilla JavaScript**, **HTML5**, and **CSS3** that helps manage lunch options with array manipulations and random selection.

![Project Status](https://img.shields.io/badge/status-active-success) ![JavaScript](https://img.shields.io/badge/javascript-%23F7DF1E.svg?style=flat&logo=javascript&logoColor=black)

## Features ✨

- **Dynamic Array Operations:** Add meals to the start or end of the menu, or remove them seamlessly using standard array methods (`push`, `unshift`, `pop`, `shift`).
- **Random Lunch Selector:** Instantly picks a random meal from your list using `Math.random()`.
- **Live Visual Feed:** Renders the current menu list dynamically on the screen alongside action logs.
- **Modern UI:** Designed with a sleek dark-mode glassmorphism aesthetic.

## Demo 🚀

Clone the repository and open `index.html` in your browser to start managing your lunch menu!
