Color Palette - CSS Colors Lab
A modern and responsive web page designed to explore and practice CSS color systems, formats, and grid layouts.

🚀 Key Features & Implementation Details
Diverse Color Formats: Showcases various CSS color models including Hexadecimal, RGB, predefined keywords, and HSL.
Flexible Grid Layout: Built using CSS Flexbox with wrapping and spacing to display color boxes cleanly across different screen sizes.
Responsive Dimensions: Uses fixed and minimum dimensions to ensure boxes remain visible and don't collapse on smaller viewports.
Modern Aesthetic: Styled with subtle border-radius and shadow effects for a polished look.
📂 Project Structure
├── index.html    # Semantic structure holding the color grid and boxes
└── styles.css    # Custom CSS styling, color models, and flexbox layout
