Stylized To-Do List Lab
A stylized and interactive To-Do List web application built as part of the Responsive Web Design curriculum. This project focuses on structuring lists and styling HTML links across different states (unvisited, visited, hovered, active, and focused).

🚀 Features
Clean and accessible HTML5 semantic structure.
Custom styling for unordered lists and nested sub-items.
Advanced CSS link states management:
Text Decoration: Removed default underlines (text-decoration: none).
Unvisited Links (:link): Styled with custom brand colors.
Visited Links (:visited): Distinct color indication for visited links.
Hover State (:hover): Interactive color transition on mouseover.
Active State (:active): Dynamic feedback color while clicking.
Focus State (:focus): Clear visual outline for keyboard accessibility.
📂 Project Structure
├── index.html    # Main HTML document containing the To-Do structure
└── styles.css    # Custom CSS styles and pseudo-class configurations
