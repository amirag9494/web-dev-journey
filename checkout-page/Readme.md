Checkout Page Lab
A clean, responsive, and accessible Checkout Page built as part of the FreeCodeCamp curriculum labs.

🚀 Features
Semantic HTML5: Uses proper structural tags (<section>, <h1>, <h2>, <form>, <label>, <input>).
Web Accessibility (A11y):
Explicitly associated labels for all form inputs.
Screen-reader friendly required field indicators (span with aria-hidden="true").
Clear error prevention and help text linked via aria-describedby.
Minimalist CSS Styling: Custom styling designed with modern system fonts, flexbox layouts, and polished form elements.
