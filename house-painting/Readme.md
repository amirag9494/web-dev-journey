# 🏡 House Painting - CSS Positioning Lab

A creative CSS positioning project built as part of the FreeCodeCamp Responsive Web Design certification. This project showcases precise element placement, stacking contexts (`z-index`), and structural layout techniques using pure HTML and CSS without relying on external frameworks or responsive width/height limitations.

## ✨ Features & Highlights

* **Absolute Positioning Mastery:** Precise placement of structural components (`chimney`, `roof`, `windows`, and `door`) relative to a relative parent container (`#house`).
* **Layering & Stacking:** Utilizes `z-index` to realistically place the chimney behind the house structure.
* **Strict Constraints Compliance:** Built cleanly without `min-width`, `max-width`, `min-height`, or `max-height` rules, strictly adhering to architectural positioning guidelines.
* **Custom Styling:** Hand-crafted borders, background colors, and dimensions to bring a digital house illustration to life.

## 🛠️ Built With

* **HTML5** (Semantic structure, nested container elements)
* **CSS3** (CSS Positioning: `relative`, `absolute`, `z-index`, dimensions, and background styling)
