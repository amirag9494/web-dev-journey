# 🏛️ Tribute Page - Maryam Mirzakhani

A responsive tribute webpage dedicated to **Maryam Mirzakhani**, the first female mathematician to win the prestigious Fields Medal. Built as part of the FreeCodeCamp Responsive Web Design certification, this project emphasizes semantic HTML structure, responsive image scaling, and clean CSS styling.

## 🚀 Features & Highlights

* **Semantic Structure:** Built using proper semantic elements (`main`, `div`, `section`, `figure`/`div`, and `a`).
* **Responsive Design:** 
  * Features a flexible layout centered on the page with a clean card-style container (`#main`).
  * The tribute image scales responsively relative to its parent using `max-width: 100%`, `height: auto`, and `display: block`.
* **Accessibility & Links:** Includes an external informational link that opens safely in a new browser tab (`target="_blank"`).

## 🛠️ Built With

* **HTML5** (Semantic markup, image embedding, lists)
* **CSS3** (Flexbox, responsive styling, typography, padding/margin layouts)
