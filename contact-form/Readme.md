Contact Form - CSS Forms Lab
A clean, modern, and accessible contact form built to practice form styling, structural layout, and interactive pseudo-classes in CSS.

🚀 Key Features & Implementation Details
Structured Layout: Built inside a centered card container (.form-container) with soft shadows, rounded corners, and padding for a polished UI.
Semantic Form Elements: Utilizes correct HTML5 form elements, matching label elements with their respective inputs using for and id attributes.
Validation & Accessibility: Includes native required attributes and robust input types (text, email) for form validation.
Interactive States: Features smooth hover transitions on the submit button to enhance user experience.
📂 Project Structure
├── index.html    # Form structure containing inputs, labels, and textareas
└── styles.css    # Styling for container layout, inputs, typography, and hover effects
