# 🚦 Traffic Light Sequencer Simulator

A web-based interactive simulation of configurable traffic light cycles and anomaly logging, built as part of JavaScript certification lab projects.

## Features
- **Configurable Cycles:** Supports multiple traffic configurations including standard cycles, invalid phase detections, system faults, and empty phase checks.
- **Interactive Visualizer:** Real-time visual traffic light box mimicking color changes and states.
- **Terminal Logging:** Built-in console log simulator tracking sequence steps, warnings, and anomalies.
- **Minimalist Aesthetic:** Designed with a warm, sepia-toned vintage dark interface.

## Technologies Used
- **JavaScript (ES6+)**: Core logic, asynchronous state handling (`async/await`), and array processing.
- **HTML5**: Semantic markup structure.
- **CSS3**: Custom properties, responsive CSS Grid layout, and glowing box-shadow animations.

## How to Run
1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. Select a configuration profile, specify the number of cycles, and click **Run Sequence**.
