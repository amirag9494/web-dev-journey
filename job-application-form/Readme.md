Job Application Form - Frontend Lab
A clean, responsive, and professionally styled job application form built to practice advanced CSS pseudo-classes, form validation states, and layout architecture.

🚀 Key Features & Implementation Details
Interactive Form Elements: Includes text inputs, email validation, dropdown selection, and radio button groups.
Dynamic Validation Styles: Utilizes :valid and :invalid pseudo-classes to provide instant visual feedback with custom border colors.
State Pseudo-Classes: Implements :focus states with custom outlines, :hover transitions for buttons, and :checked styles for interactive radio options.
Structural Selectors: Leverages advanced selectors like :first-of-type to uniquely style form components.
Modern Aesthetic: Clean, minimalist design with a structured container layout and responsive sizing.
📂 Project Structure
├── index.html    # Semantic HTML5 structure and form elements
└── styles.css    # Custom CSS3 styling, validation rules, and pseudo-classes
