Feature Selection Page
A clean, responsive, and modern feature selection interface built to practice custom CSS checkboxes, CSS Grid layouts, and interactive card hover states.

🚀 Key Features & Implementation Details
Grid Layout: Designed using CSS Grid to organize feature cards into a neat, balanced 2-column layout.
Custom Checkboxes: Utilizes appearance: none; to completely reset native browser checkboxes, replacing them with a custom-styled border box and a centered checkmark (✓) when selected.
Interactive Hover Effects: Feature cards elevate and highlight smoothly on mouseover to provide immediate visual feedback.
Semantic HTML: Employs semantic label elements wrapped around cards to improve accessibility and usability.
📂 Project Structure
├── index.html    # Main page structure with feature cards, titles, descriptions, and checkboxes
└── styles.css    # Layout styling, Grid setup, custom checkbox states, and hover effects
