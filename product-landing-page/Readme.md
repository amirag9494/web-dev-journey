# ☕ Artisan Brews - Product Landing Page

A modern, responsive, and aesthetically pleasing product landing page built as part of the freeCodeCamp Responsive Web Design certification. This project showcases clean semantic HTML5 structure, advanced CSS Flexbox layouts, media queries for mobile responsiveness, and a vintage-modern artisan coffee theme.

## ✨ Features & Design Highlights

* **Fixed Navigation Bar (`#header`):** Always stays pinned to the top of the viewport with smooth links to main sections.
* **Responsive Flexbox Architecture:** Utilizes CSS Flexbox for fluid alignment across the navigation, feature boxes, and layout structures.
* **Email Collection Form:** Features a fully compliant HTML5 validated email input field wired up to mock submission handlers.
* **Embedded Media:** Integrated responsive video container showcasing product creation processes.
* **Mobile-First Media Queries:** Dynamically adapts layout structures, header alignments, and form elements for seamless viewing on smaller screens.
* **Artisan Aesthetic:** Styled with warm earth tones, card-based UI containers, and crisp typographic hierarchies.

## 🛠️ Built With

* **HTML5** (Semantic elements: `<header>`, `<nav>`, `<main>`, `<section>`, `<iframe>`, `<form>`)
* **CSS3** (Flexbox, Custom Properties, Media Queries, Shadows, Transitions)
