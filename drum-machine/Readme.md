# Drum Machine 🥁

This project is an interactive **Drum Machine** developed as part of the *Front End Development Libraries* certification challenges on **freeCodeCamp**. With this app, you can create beats by clicking the pads or pressing the corresponding keys on your keyboard.

## 🌟 Features

* **Real-Time Audio Playback:** Instant sound triggering with zero delay.
* **Keyboard Support:** Play the drum pads using designated keys on your keyboard.
* **Dynamic Status Display:** Shows the name of the currently playing audio clip on the screen.
* **Engaging UI:** Minimalist, classic design with visual feedback (active states) when buttons are pressed.
* **Fully Tested:** Built to pass all strict freeCodeCamp automated tests.

## 🛠 Technologies Used

* **HTML5:** For the semantic structure of the pads and nesting the `<audio>` elements.
* **CSS3:** For styling, hover/active effects, and layout design.
* **JavaScript (Vanilla):** For DOM manipulation and handling `click` and `keydown` event listeners.

## 🎹 Key Map Guide

You can use the following keys on your keyboard to trigger the sounds:

| Keyboard Key | Sound Name |
| :---: | :--- |
| **Q** | Heater-1 |
| **W** | Heater-2 |
| **E** | Heater-3 |
| **A** | Heater-4 |
| **S** | Clap |
| **D** | Open-HH |
| **Z** | Kick-n-Hat |
| **X** | Kick |
| **C** | Closed-HH |

## 🚀 Installation & Usage

You don't need to install any packages or tools to run this project locally:

1. Download or clone the project files.
2. Ensure `index.html`, `styles.css`, and `script.js` are all in the same directory.
3. Open `index.html` in your preferred web browser (Chrome, Firefox, Safari, etc.).
4. Start playing the drums!
