# Gradebook Application

A lightweight JavaScript application designed to calculate class averages, grade individual student performances based on standard thresholds, and output pass/fail feedback messages.

## Features
- **Average Calculation (`getAverage`)**: Computes the mean score of an array of test scores.
- **Grading System (`getGrade`)**: Converts numerical scores into letter grades (`A+` to `F`).
- **Pass/Fail Validation (`hasPassingGrade`)**: Evaluates if a grade qualifies as passing.
- **Dynamic Messaging (`studentMsg`)**: Generates a complete diagnostic report combining class statistics and individual results.

## Technologies Used
- **JavaScript (ES6+)** for core algorithms and DOM manipulation.
- **HTML5 & CSS3** for a clean, responsive user interface.
