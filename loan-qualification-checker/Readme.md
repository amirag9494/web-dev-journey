# Loan Eligibility Checker 💳✨

A sleek, modern web utility built with **Vanilla JavaScript**, **HTML5**, and **CSS3** that determines loan qualification based on annual income and credit score.

![Project Status](https://img.shields.io/badge/status-active-success) ![JavaScript](https://img.shields.io/badge/javascript-%23F7DF1E.svg?style=flat&logo=javascript&logoColor=black)

## Features ✨

- **Multi-Tier Loan Evaluation:** Checks eligibility for multiple loan types (Duplex, Condo, and Car loans) based on specific financial criteria.
- **Interactive UI:** Clean input fields with real-time feedback and dynamic results container.
- **Glassmorphism Design:** Styled with a modern dark-mode aesthetic, glowing borders, and smooth gradients.
- **Responsive Layout:** Looks stunning and works seamlessly across all devices.

## Demo 🚀
