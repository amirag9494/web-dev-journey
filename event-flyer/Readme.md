Event Flyer Page - HTML & CSS Lab
A responsive and modern event flyer web page built to practice core CSS layout techniques, viewport units, mathematical functions (calc), and strict structural requirements.

🚀 Key Features & Implementation Details
Semantic HTML5 Structure: Built using proper semantic landmarks including header, main, section, and hr elements.
Viewport-Based Sizing: Leverages vw units on the body element to ensure fluid scaling across screen sizes.
Dynamic Height Calculation: Utilizes the CSS calc() function to set a dynamic minimum height (100vh - 100px).
Centered Fluid Layout: Configured with symmetric padding (50px 0), zero top/bottom margins, and auto horizontal margins.
Relative Width Proportions: All structural section and divider (hr) elements use percentage-based widths relative to their parent container.
📂 Project Structure
├── index.html    # Semantic HTML5 layout and event content
└── styles.css    # Custom CSS using calc(), viewport units, and flexbox
